## About

The repository contains two private [Discord](https://discord.com) bots built with C# (DSharpPlus) designed to help moderate and manage a community.

Gir supports moderation, color roles, greetings, temporary voices, tickets etc. when Kuromi handles music.

<p align="right">(<a href="#readme-top">back to top</a>)</p>

## Getting Started

### 1. Clone the Repository

```
git clone https://github.com/fnaxi/Gir.git Gir
cd Gir
```

### 2. Set bot token

Copy `Core/Config/Config.ini` to the root and change token fields to the tokens you want to use. Then run `CopyConfigToBinaries.bat` script.

### 3. Open solution

Open `Gir.sln` and build all the projects.
